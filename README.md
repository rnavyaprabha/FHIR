FHIR Client Project
This project aims to explore and understand HL7 FHIR (Fast Healthcare Interoperability Resources) standards by implementing client-side JavaScript code to perform Create, Read, Update, and Delete (CRUD) operations on FHIR resources using RESTful APIs. The objective is to gain hands-on experience interacting with a FHIR server and building familiarity with FHIR data structures and schemas.

Features
Create FHIR resources (e.g., Patient, Observation) using HTTP POST

Read resources via HTTP GET

Update resources using HTTP PUT

Delete resources via HTTP DELETE

Search for resources using query parameters

Validate FHIR resource structures using fhir.schema.json

Configure Visual Studio Code for FHIR schema validation and auto-completion

Tools Used
Node.js for executing JavaScript code

Axios for making HTTP requests

Visual Studio Code with JSON schema support

FHIR schema (fhir.schema.json) from HL7 for syntax checking

HAPI FHIR server (local Docker setup) for development and testing

Insomnia for API testing and exploration
=======
This project is aimed at understanding and exploring HL7 FHIR (Fast Healthcare Interoperability Resources) standards, particularly how to create, read, update, and delete FHIR resources using RESTful APIs. The goal is to gain hands-on experience interacting with a FHIR server and building familiarity with FHIR data structures and schemas.

What This Project Covers
Creating FHIR resources (e.g., Patient) using REST methods (POST, PUT)

Retrieving and updating resources via GET and PATCH

Deleting resources from the FHIR server (DELETE)

Learning the structure and validation rules of FHIR using fhir.schema.json from HL7

Configuring Visual Studio Code for FHIR schema validation and auto-completion

Using Insomnia to simulate and test API interactions with a FHIR server

Tools Used
Insomnia for API testing and exploration

VS Code with FHIR JSON schema support for validating and editing resource definitions

FHIR schema (fhir.schema.json) from HL7 for syntax checking

HAPI FHIR server (local Docker setup) for local development and testing- https://github.com/rnavyaprabha/hapi-fhir-jpaserver-starter
